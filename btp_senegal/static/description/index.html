BTP SENEGAL

Application Odoo 19 dédiée aux entreprises BTP au Sénégal : gestion de chantier, étude de prix (ouvrages / sous-détails), devis (DQE) et budget chantier, avec analytique par chantier (logique OHADA).

Fonctionnalités incluses

  • Référentiels BTP (natures de ressources, catégories de coûts, zones, types de marchés)
  • Chantiers : centre analytique auto (plan « Chantiers »), workflow, chatter
  • Bibliothèque d'ouvrages : versions, sous-détail de prix, calcul déboursé sec → prix de vente
  • Devis (DQE) : lignes par ouvrage + version validée, totaux déboursé / vente
  • Budget chantier : initial/révisé + assistant « Devis validé → Budget »
